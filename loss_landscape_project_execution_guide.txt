Problem: Investigating the Loss Landscape of Deep Neural Networks

======================================================================
1. PROJECT OBJECTIVE
======================================================================

The objective is to investigate how neural-network architecture,
optimization algorithms, and weight initialization affect training
behaviour and the geometry of the loss landscape.

The project will:

1. Generate a reproducible nonlinear classification dataset.
2. Build fully connected neural networks with configurable depth and
   width.
3. Train networks using SGD, SGD with Momentum, and Adam.
4. compare training loss, test accuracy, and convergence behaviour.
5. Visualize two-dimensional slices of the loss landscape around a
   trained set of weights.
6. Examine flat/sharp regions and discuss possible saddle points and
   local minima.
7. Investigate the effect of Xavier and He initialization.
8. Record experimental results and prepare evidence for the report
   and viva.

Important scientific qualification:
A two-dimensional loss-landscape plot is a slice through a very
high-dimensional parameter space. It does not show the entire
landscape and cannot, by itself, prove that a point is a local or
global minimum or a saddle point. The report must describe what the
visualization actually demonstrates.

The project uses a Two Moons synthetic classification dataset as an
initial controlled testbed. It is suitable for learning and visualizing
nonlinear classification. It is not a substitute for experiments on
large-scale real-world datasets.

Create dataset.py and paste:

    import matplotlib.pyplot as plt
    import torch
    from sklearn.datasets import make_moons
    from sklearn.model_selection import train_test_split
    from sklearn.preprocessing import StandardScaler


    def get_data(random_state=42):
        # Generate 2,000 two-dimensional samples in two classes.
        X, y = make_moons(
            n_samples=2000,
            noise=0.20,
            random_state=random_state
        )

        # Keep 20% for final testing. Stratification preserves
        # approximately the same class proportions in both splits.
        X_train, X_test, y_train, y_test = train_test_split(
            X,
            y,
            test_size=0.20,
            random_state=random_state,
            stratify=y
        )

        # Fit the scaler on training data only to avoid data leakage.
        scaler = StandardScaler()
        X_train = scaler.fit_transform(X_train)
        X_test = scaler.transform(X_test)

        # Convert arrays into PyTorch tensors.
        X_train = torch.tensor(X_train, dtype=torch.float32)
        X_test = torch.tensor(X_test, dtype=torch.float32)
        y_train = torch.tensor(y_train, dtype=torch.long)
        y_test = torch.tensor(y_test, dtype=torch.long)

        return X_train, X_test, y_train, y_test


    def plot_dataset():
        X, y = make_moons(
            n_samples=2000,
            noise=0.20,
            random_state=42
        )

        plt.figure(figsize=(8, 6))
        plt.scatter(
            X[:, 0],
            X[:, 1],
            c=y,
            cmap="coolwarm",
            edgecolors="black",
            linewidths=0.25,
            s=18
        )
        plt.title("Two Moons Dataset")
        plt.xlabel("Feature 1")
        plt.ylabel("Feature 2")
        plt.tight_layout()
        plt.savefig("results/figures/two_moons_dataset.png", dpi=200)
        plt.show()


    if __name__ == "__main__":
        import os

        X_train, X_test, y_train, y_test = get_data()

        print("Training samples:", len(X_train))
        print("Testing samples:", len(X_test))
        print("Number of input features:", X_train.shape[1])
        print("Number of classes:", len(torch.unique(y_train)))

        plot_dataset()

8. FILE 2: model.py
======================================================================

Purpose:
- Build a fully connected feedforward neural network.
- Allow depth and width to be changed for experiments.
- Support Xavier and He (Kaiming) initialization.

Create model.py and paste:

    import torch.nn as nn


    class NeuralNetwork(nn.Module):
        def __init__(
            self,
            input_size=2,
            hidden_size=16,
            num_hidden_layers=2,
            output_size=2,
            initialization="he"
        ):
            super().__init__()

            if num_hidden_layers < 1:
                raise ValueError("num_hidden_layers must be at least 1")

            layers = []
            in_features = input_size

            for _ in range(num_hidden_layers):
                linear = nn.Linear(in_features, hidden_size)
                layers.append(linear)
                layers.append(nn.ReLU())
                in_features = hidden_size

            layers.append(nn.Linear(in_features, output_size))
            self.network = nn.Sequential(*layers)

            self.initialize_weights(initialization)

        def initialize_weights(self, initialization):
            for module in self.modules():
                if isinstance(module, nn.Linear):
                    if initialization == "xavier":
                        nn.init.xavier_uniform_(module.weight)
                    elif initialization == "he":
                        nn.init.kaiming_uniform_(
                            module.weight,
                            nonlinearity="relu"
                        )
                    elif initialization == "default":
                        # Keep PyTorch's default Linear initialization.
                        pass
                    else:
                        raise ValueError(
                            "initialization must be "
                            "'xavier', 'he', or 'default'"
                        )

                    nn.init.zeros_(module.bias)

        def forward(self, x):
            return self.network(x)

The output layer returns two raw scores (logits). Do not add softmax
to the model when using nn.CrossEntropyLoss; that loss function
expects logits and applies the appropriate normalization internally.

Create train.py and paste:

    import os
    import random
    import numpy as np
    import pandas as pd
    import torch
    import torch.nn as nn
    import matplotlib.pyplot as plt

    from dataset import get_data
    from model import NeuralNetwork


    def set_seed(seed=42):
        random.seed(seed)
        np.random.seed(seed)
        torch.manual_seed(seed)


    def build_optimizer(name, parameters, learning_rate):
        if name == "sgd":
            return torch.optim.SGD(
                parameters,
                lr=learning_rate
            )

        if name == "momentum":
            return torch.optim.SGD(
                parameters,
                lr=learning_rate,
                momentum=0.9
            )

        if name == "adam":
            return torch.optim.Adam(
                parameters,
                lr=learning_rate
            )

        raise ValueError("Unknown optimizer: " + name)


    def evaluate(model, X_test, y_test):
        model.eval()
        with torch.no_grad():
            logits = model(X_test)
            predictions = torch.argmax(logits, dim=1)
            accuracy = (predictions == y_test).float().mean().item()

        return accuracy


    def train_model(
        optimizer_name="adam",
        hidden_size=16,
        num_hidden_layers=2,
        initialization="he",
        epochs=200,
        learning_rate=0.01,
        seed=42,
        run_name="baseline"
    ):
        set_seed(seed)
        os.makedirs("results/figures", exist_ok=True)
        os.makedirs("results/checkpoints", exist_ok=True)
        os.makedirs("results/tables", exist_ok=True)

        X_train, X_test, y_train, y_test = get_data()

        model = NeuralNetwork(
            input_size=2,
            hidden_size=hidden_size,
            num_hidden_layers=num_hidden_layers,
            output_size=2,
            initialization=initialization
        )

        criterion = nn.CrossEntropyLoss()
        optimizer = build_optimizer(
            optimizer_name,
            model.parameters(),
            learning_rate
        )

        history = []

        for epoch in range(epochs):
            model.train()

            logits = model(X_train)
            loss = criterion(logits, y_train)

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()

            history.append({
                "epoch": epoch + 1,
                "training_loss": loss.item()
            })

            if (epoch + 1) % 20 == 0:
                print(
                    f"{run_name} | Epoch {epoch + 1}/{epochs} "
                    f"| Loss: {loss.item():.5f}"
                )

        test_accuracy = evaluate(model, X_test, y_test)
        final_training_loss = history[-1]["training_loss"]

        print("\nRun:", run_name)
        print("Optimizer:", optimizer_name)
        print("Final training loss:", round(final_training_loss, 5))
        print("Test accuracy:", round(test_accuracy * 100, 2), "%")

        # Save model weights and configuration.
        checkpoint_path = (
            f"results/checkpoints/{run_name}.pt"
        )

        torch.save({
            "model_state_dict": model.state_dict(),
            "hidden_size": hidden_size,
            "num_hidden_layers": num_hidden_layers,
            "initialization": initialization,
            "optimizer": optimizer_name,
            "learning_rate": learning_rate,
            "seed": seed,
            "test_accuracy": test_accuracy,
            "final_training_loss": final_training_loss
        }, checkpoint_path)

        # Save epoch-by-epoch training history.
        history_path = f"results/tables/{run_name}_history.csv"
        pd.DataFrame(history).to_csv(history_path, index=False)

        # Save loss graph.
        plt.figure(figsize=(8, 5))
        plt.plot(
            [row["epoch"] for row in history],
            [row["training_loss"] for row in history]
        )
        plt.xlabel("Epoch")
        plt.ylabel("Training Cross-Entropy Loss")
        plt.title(f"Training Loss - {run_name}")
        plt.grid(True, alpha=0.3)
        plt.tight_layout()
        plt.savefig(
            f"results/figures/{run_name}_loss.png",
            dpi=200
        )
        plt.close()

        return {
            "run_name": run_name,
            "optimizer": optimizer_name,
            "hidden_size": hidden_size,
            "num_hidden_layers": num_hidden_layers,
            "initialization": initialization,
            "final_training_loss": final_training_loss,
            "test_accuracy": test_accuracy,
            "checkpoint": checkpoint_path
        }


    if __name__ == "__main__":
        result = train_model(
            optimizer_name="adam",
            hidden_size=16,
            num_hidden_layers=2,
            initialization="he",
            epochs=200,
            learning_rate=0.01,
            seed=42,
            run_name="baseline_adam"
        )

10. FILE 4: landscape.py
======================================================================

Purpose:
- Load a trained checkpoint.
- Construct two directions in parameter space.
- Evaluate loss on a grid around the trained parameters.
- Plot a 3D surface and a 2D contour map.

Concept:
Let theta* be the trained parameter vector. Let d1 and d2 be two
directions in parameter space. We evaluate:

    L(alpha, beta) = Loss(theta* + alpha*d1 + beta*d2)

The resulting grid is a two-dimensional slice through the full
parameter space.

Create landscape.py and paste:

    import os
    import numpy as np
    import torch
    import torch.nn as nn
    import matplotlib.pyplot as plt

    from dataset import get_data
    from model import NeuralNetwork


    def make_filter_normalized_direction(model):
        direction = []

        for parameter in model.parameters():
            if parameter.ndim >= 2:
                random_direction = torch.randn_like(parameter)

                # Normalize each weight tensor's direction to the
                # scale of its corresponding parameter tensor.
                direction_norm = torch.norm(random_direction)
                parameter_norm = torch.norm(parameter)

                if direction_norm > 0:
                    random_direction = (
                        random_direction / direction_norm
                    ) * parameter_norm

                direction.append(random_direction)
            else:
                # Keep bias directions zero in this visualization.
                direction.append(torch.zeros_like(parameter))

        return direction


    def add_directions(base_parameters, direction1, direction2,
                       alpha, beta):
        with torch.no_grad():
            for parameter, base, d1, d2 in zip(
                model.parameters(),
                base_parameters,
                direction1,
                direction2
            ):
                parameter.copy_(base + alpha * d1 + beta * d2)


    def main():
        global model

        os.makedirs("results/figures", exist_ok=True)

        checkpoint_path = "results/checkpoints/baseline_adam.pt"

        if not os.path.exists(checkpoint_path):
            raise FileNotFoundError(
                "Checkpoint not found. Run python train.py first."
            )

        checkpoint = torch.load(
            checkpoint_path,
            map_location="cpu",
            weights_only=False
        )

        model = NeuralNetwork(
            input_size=2,
            hidden_size=checkpoint["hidden_size"],
            num_hidden_layers=checkpoint["num_hidden_layers"],
            output_size=2,
            initialization=checkpoint["initialization"]
        )

        model.load_state_dict(checkpoint["model_state_dict"])
        model.eval()

        X_train, X_test, y_train, y_test = get_data()
        criterion = nn.CrossEntropyLoss()

        base_parameters = [
            parameter.detach().clone()
            for parameter in model.parameters()
        ]

        torch.manual_seed(123)
        direction1 = make_filter_normalized_direction(model)
        direction2 = make_filter_normalized_direction(model)

        # Use a 21 by 21 grid. Increase resolution only after the
        # basic experiment works.
        coordinates = np.linspace(-1.0, 1.0, 21)
        loss_grid = np.zeros((len(coordinates), len(coordinates)))

        for i, alpha in enumerate(coordinates):
            for j, beta in enumerate(coordinates):
                add_directions(
                    base_parameters,
                    direction1,
                    direction2,
                    alpha,
                    beta
                )

                with torch.no_grad():
                    loss = criterion(model(X_train), y_train)

                loss_grid[j, i] = loss.item()

        # Restore the exact trained parameters.
        with torch.no_grad():
            for parameter, base in zip(
                model.parameters(),
                base_parameters
            ):
                parameter.copy_(base)

        A, B = np.meshgrid(coordinates, coordinates)

        # 3D surface plot.
        figure = plt.figure(figsize=(10, 7))
        axis = figure.add_subplot(111, projection="3d")
        axis.plot_surface(
            A,
            B,
            loss_grid,
            cmap="viridis",
            edgecolor="none"
        )
        axis.set_xlabel("Direction 1 coefficient")
        axis.set_ylabel("Direction 2 coefficient")
        axis.set_zlabel("Training loss")
        axis.set_title("2D Slice of the Neural Network Loss Landscape")
        plt.tight_layout()
        plt.savefig(
            "results/figures/loss_landscape_3d.png",
            dpi=200
        )
        plt.close()

        # 2D contour plot.
        plt.figure(figsize=(8, 6))
        contour = plt.contourf(
            A,
            B,
            loss_grid,
            levels=30,
            cmap="viridis"
        )
        plt.colorbar(contour, label="Training loss")
        plt.scatter([0], [0], color="red", marker="x",
                    s=100, label="Trained parameters")
        plt.xlabel("Direction 1 coefficient")
        plt.ylabel("Direction 2 coefficient")
        plt.title("Loss Landscape Contour")
        plt.legend()
        plt.tight_layout()
        plt.savefig(
            "results/figures/loss_landscape_contour.png",
            dpi=200
        )
        plt.show()


    if __name__ == "__main__":
        main()

Interpretation:
- A valley-like region indicates lower loss in the displayed slice.
- A steep region indicates loss changes rapidly along the selected
  directions.
- A relatively flat region indicates loss changes slowly along the
  selected directions.
- The red cross is the trained parameter point (alpha=0, beta=0).

Caution:
The two random directions are only a visualization basis. A valley,
flat region, or saddle-like shape in this slice is not definitive proof
of the corresponding property in the complete parameter space.
To make stronger claims about minima or saddle points, use additional
directions, local curvature/Hessian analysis, and repeated runs.

18. TROUBLESHOOTING
======================================================================

Problem: "python is not recognized"
- Reinstall Python and enable Add Python to PATH.
- Restart VS Code.
- Try the Windows launcher:

      py --version

Problem: PowerShell refuses to activate .venv
- Switch VS Code terminal to Command Prompt.
- Run:

      .venv\Scripts\activate.bat

Problem: ModuleNotFoundError
- Confirm the .venv interpreter is selected.
- Activate .venv.
- Run:

      python -m pip install -r requirements.txt

Problem: PyTorch import fails
- Check the selected interpreter.
- Reinstall using:

      python -m pip install torch

Problem: landscape.py says checkpoint not found
- Run:

      python train.py

  first, and check that results/checkpoints/baseline_adam.pt exists.

Problem: A plot window does not appear
- Check whether the PNG file was saved under results/figures.
- If running remotely or without a graphical display, inspect the
  saved PNG rather than relying on plt.show().

Problem: Git push is rejected
- Confirm the remote URL:

      git remote -v

- Confirm that the GitHub repository exists and that you have access.
- If the remote repository already contains commits, inspect and
  reconcile the histories rather than force-pushing blindly.
